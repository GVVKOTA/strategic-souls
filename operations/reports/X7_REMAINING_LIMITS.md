# X7 remaining limits

- Personal Angel One quotes and candles are owner-only. Other accounts need an entitled licensed source or must select a permitted source such as official ECB reference FX or private CSV.
- 30-minute and hourly scans are disabled. Daily endpoints cannot substitute for genuine intraday candle history.
- The daily-history ceiling is 2,000 calendar days on the revised adapter. The scanner may use smaller windows and defer candidates. Requests requiring a longer window or lacking upstream history report insufficient data. Multi-window backfill and provider retention beyond the tested windows remain unverified.
- Exchange calendars and broker profiles have finite coverage. Historical corporate action vintages are unavailable through the current broker input. Point-in-time adjusted backtests and outcome probabilities remain unavailable where provenance fails the evidence gate.
- The new draft has no production Worker version. Exact live deployment metadata could not be read with the current Cloudflare authorization. Genuine owner coverage from the previous release does not establish X7 behavior.
- Timed mobile and desktop browser exercises for all X7 workflow branches, production slow-provider tests, and CPU/memory benchmarking remain open. The cross-product suites cover regression fixtures; a comprehensive owner/member browser audit was not run.
