# X 1.0 workspace rollout

This rollout brings the verified workspace improvements to the existing production app. GitHub main and the live Worker remain the sources of build and deployment identity. The release endpoint identifies the X 1.0 workspace and the serving data runtime separately.

| Area | Included |
| --- | --- |
| Header and Global | India identity, grouped Global menu, current eight-card roster, bookmarks and browser history |
| Strategic Globe | Zoom-driven transition between the existing NASA Earth and the lazy regional map with bundled Natural Earth geography |
| Research | Existing scan execution and quotas, formula tools, asset lookup and comparison, rights-aware company statement periods and market coverage |
| Personal workspace | Portfolio valuations with coverage labels, ledger corrections, watchlist entry points, notification destinations and price alert controls |
| Community and settings | Chat and room entry points, linked messages and Soul posts, existing follow approvals and privacy, session controls |

The production data runtime retains the existing owner-only private market connection and public official reference sources. The India API and BharatStock integrations require verified provider grants. Full Nifty 500 scans, shared exchange history, licensed-only heatmap coverage and active price alert monitoring require the approved data and scheduling. The production workspace rollout does not satisfy those full-release gates. [X 1.0 full implementation and acceptance](https://github.com/GVVKOTA/strategic-souls/pull/7)

Migrations 0012–0019 match the additive migrations already applied to production. The workspace rollout uses their notification views and portfolio correction records and preserves the existing database, accounts and user data. Follow the [production release runbook](DEPLOYMENT_RUNBOOK.md) for build verification, zero-traffic testing, promotion and rollback.
