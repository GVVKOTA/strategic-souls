# Free data and licence matrix

Checked 14 November 2026 against official primary sources. This is a documented implementation boundary, not counsel or exchange approval.

| Source | Cost / rights evidence | Approved implementation boundary |
|---|---|---|
| TradingView widgets | Free default-branded widgets; stock data can be delayed, supported FX/crypto real-time; paid personal plan does not upgrade embeds | Vendor-hosted human viewing with attribution. No raw API, extraction, scans, scores, alerts or NAV. Symbol availability varies. |
| EIA Open Data | Free registered key; government information generally reusable with attribution/publication date, excluding protected third-party content | Optional official macro release research. No key configured; no dataset ingested. Weekly statistics are not oil quotes. |
| Upstox V3 | Free API offering; account authorization and Protobuf WebSocket | Optional internal account-linked development only. Public redistribution grant not established; disabled. No trading. |
| Twelve Data Basic | $0; 8 API credits/minute, 800/day; internal non-display | Local/test use only; not public commercial display. Disabled. |
| CoinGecko Demo | FAQ updated 19 October 2026 excludes commercial rights | Not used as the business data foundation. Attribution is insufficient. |
| NSE / BSE / MCX data | Public redistribution and derived/non-display uses require appropriate agreements | No scraping or broker-feed rebroadcast. No numeric exchange-data licence established. |
| Binance / FRED third-party series | Endpoint access does not establish commercial redistribution rights | No public numeric integration or inferred blanket rights. |

Primary sources: [TradingView widgets](https://www.tradingview.com/widget/), [data FAQ](https://www.tradingview.com/widget-docs/faq/data/), [integration/branding/privacy FAQ](https://www.tradingview.com/widget-docs/faq/general/), [policies](https://www.tradingview.com/policies/); [EIA API](https://www.eia.gov/opendata/), [EIA reuse](https://www.eia.gov/about/copyrights_reuse.php) (official search excerpt; direct fetch timed out); [Upstox API](https://upstox.com/trading-api/), [V3 feed](https://upstox.com/developer/api-documentation/v3/get-market-data-feed/); [Twelve pricing](https://twelvedata.com/pricing), [usage](https://support.twelvedata.com/en/articles/5332349-commercial-and-personal-usage); [CoinGecko licensing](https://support.coingecko.com/articles/1043089972-what-are-the-differences-between-commercial-and-custom-licenses); [NSE policy](https://www.nseindia.com/static/market-data/nse-data-policy).

All provider prices, limits and terms can change. No purchase, account connection or signed agreement was made. Zero new paid market-data subscriptions were added.
