## Adapter contract and operation

The authenticated same-origin GET `/api/x1/markets` calls `loadMarketData`. Every numeric observation includes provider, source URL, source DATE, actual server retrieval timestamp, currency, units, data state, derivation, change unit and analysis eligibility. DATE precision is explicit: midnight is not invented as the exchange-event time. The server response has a separate `asOf` timestamp for the clock. Missing values are null, never zero. FX daily changes use same-series dated observations; Treasury changes multiply percentage-point differences by 100 into basis points.

For current scans, the 90-day ECB history can supply deterministic close-based research over an explicitly FX universe. Every historical point's `knownAt` is conservatively the current retrieval time: the feed supplies no exact original release timestamps or revision vintages. It cannot establish point-in-time historical backtest eligibility, intraday OHLC/volume, fundamental or equity scanning rights. Re-fetching public history is not evidence that it was known to a past user at a past instant.

Both fixed HTTPS provider URLs are fetched server-side in parallel, each with an 8-second abort deadline, 500,000-byte response budget, bounded scalar XML parser, date/value/identity checks, a 15-minute isolate-local cache, in-flight request deduplication and a one-minute failure retry backoff. Fetch uses the Workers-supported manual redirect mode and explicitly rejects all 3xx responses, already-followed responses and changed final URLs. It never requests a Location destination. Malformed/future responses cannot overwrite accepted data. A failed provider retains its last good observation with STALE status; a provider with no prior observation returns UNAVAILABLE. The two providers fail independently. Product-facing failure reasons are sanitized; runtime or parser exception text is not copied into API output. No WebSocket or background paid task is started.

The cache is intentionally ephemeral: cold Worker isolates can re-fetch, and last-good observations do not survive isolate eviction. This is not a distributed ingestion-rate guarantee or durable cache. Before broader audience/scaling, persist bounded public-source caches and global fetch leases using existing D1/appropriate platform storage, and validate provider traffic policy. There is no claimed provider SLA or published request-rate entitlement. Do not use the one-minute retry ceiling as a provider-approved rate limit.

## Read evidence, tests and costs

The implemented Node adapter was probed directly on 17 November 2026 at 14:04:27 UTC. Both real endpoints returned valid dated observations; these are read-only network calls, not fixtures. An earlier Python Treasury probe timed out, which was resolved by testing the actual Node adapter and correct monthly XML URL. The lead's subsequent real local Cloudflare Worker preview exposed that redirect:error is unsupported at the edge, despite working in Node. It was corrected to manual mode with explicit redirect rejection. After that fix, another real Node probe at 2026-11-17T14:33:36.735Z returned both providers CONNECTED, 13 numeric FX rates, five yields and 13 FX histories, still source-dated 2026-11-16. The rebuilt Worker and deployed owner browser must still be checked by the lead; a local Node API success is not edge or deployed proof.

Executed `node --experimental-strip-types --test tests/x1-market.test.mjs`: **22 passed, 0 failed**, latest measured duration **238.3 ms**. Cases cover independent outages, malformed/future XML, missing tenors, date-vs-fetch freshness, derived cross-rate identity, basis points, retained stale values, cache/dedup/backoff, coordinate clusters, DST, holidays and half-day session boundaries. Four regression cases also emulate the Worker redirect-mode restriction, reject HTTP redirect destinations, reject already-followed/changed-destination responses and prevent raw runtime details leaking into Source Health. Fixture tests do not prove a perpetual source connection.

Incremental provider API subscription fee for these official feeds: **USD 0**; no key, license purchase or account was created. Existing Sites hosting, D1 writes, network, CPU and storage fees depend on the owner's plan and observed traffic; these costs are **unverified**, not claimed free. A planning bound (not a bill forecast): one continuously active warm isolate at two requests per 15 minutes makes at most 192 successful provider requests/day. At the deliberately conservative 500 KB/document cap, that is 2.88 GB inbound/30 days/isolate; actual ECB90 payload in the probe was 69,510 bytes and on-demand traffic is usually lower. Cold starts and outage retries can raise request counts. Browser egress additionally includes requested JSON history; no historical data is embedded in initial HTML.

For paid equities/indices/non-display scans, vendor, venue, instrument count, display audience, cache retention, redistribution, socket count and historical storage must be costed in a founder-approved agreement. No numeric price quote is substituted for unknown licensing costs. Payments and public content publishing remain outside this data-adapter activation.
